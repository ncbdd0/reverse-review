# 逆向工程复习站

软件逆向工程课程复习网站（纯静态站点，部署于 GitHub Pages）。

## 功能

- **访问密码门**：全站内容（题库 + 文档）以 AES-256-GCM 加密存放，凭访问密码在浏览器端解密；密码不存储在任何服务器或仓库中。
- **账号体系与云同步**：登录同一账号密码，错题本、练习进度、上传文档（≤150KB）跨设备同步；数据加密后经第三方 KV 服务中转，带 HMAC 完整性校验；另有「同步码」离线兜底。
- **背题模式**：直接显示正确答案，支持「遮挡答案」自测，逐题点开。
- **做题模式**：正式作答，点击「下一题」后才显示正确答案与解析，自动判分。
- **错题本**：背题/做题模式均可加入，自由增删、标记已掌握、错题重练。
- **文档中心**：内置课程 PDF 在线阅读（pdf.js）与下载；支持上传自定义文档保存在站内。

## 题库来源

《复习思考题（第2和7章）--2024级》共 73 题：填空 19（挖空位置与原卷下划线一致）、单选 25、判断 23、简答 5、分析 1。

## 目录

- `index.html` / `assets/` — 站点代码（原生 JS，无依赖框架）
- `assets/pdf.min.js` / `pdf.worker.min.js` — pdf.js (pdfjs-dist 3.11.174, Apache-2.0)
- `data/bundle.enc`、`docs/*.enc` — AES-256-GCM 加密内容
